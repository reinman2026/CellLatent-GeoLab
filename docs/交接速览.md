当前五页已统一为六维表达、三维潜空间、六维重建。
每个细胞用均值和标准差定义一个三维椭球。
潜空间页先拟合两池动力学参数，再显示 UMAP 二维轨迹和速度箭头。

## A 最新版本的计算路径

```flow
六维表达 -> 固定标准化: 24 个合成细胞
固定标准化 -> 八个隐藏单元: 编码器
八个隐藏单元 -> 三维均值与方差: 两个输出头
三维均值与方差 -> 每个细胞的椭球: 中心 μ，半轴 k√v
三维均值与方差 -> 两池动力学参数: α、β、γ
两池动力学参数 -> UMAP 二维图: 轨迹与速度箭头
三维均值与方差 -> 均值或样本: 解码输入
均值或样本 -> 六维重建: 解码器
```

当前网页直接重建表达，省略真实 RegVelo 的时间与动力学计算。

## C 椭球含义保持一致

| 属性 | 当前含义 |
|---|---|
| 中心 | 三维均值 μ |
| 三条半轴 | k × 标准差 √v |
| 粉色点 | 当前抽样 z |
| 灰色虚线椭球 | 本轮训练开始前的分布 |
| 1σ 轮廓 | 包含约 19.9% 的三维概率 |
| 95% 轮廓 | k 约为 2.795 |
| 两池速度 | α(s)、β、γ 计算表达速度，再映射到潜空间 |

重抽样保持椭球中心与形状不变。
改变视角或轮廓不改变解码输入。
