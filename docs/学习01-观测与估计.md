RegVelo 用观测到的 S/U 表达，约束细胞状态、潜在时间和调控动力学参数。
这些未知量通过共同解释表达数据来估计。

## A 先在网页中找到一个细胞

打开离线版的“三空间总览”，选中 C01。
观察左侧六维表达、中间三维椭球和右侧六维重建。
六项表达的顺序为 S_A、S_B、S_C、U_A、U_B、U_C。

S 对应 spliced RNA（已剪接 RNA）。
U 对应 unspliced RNA（未剪接 RNA）。
两者是两池动力学模型中的两个分子池。

| 网页位置 | 所代表的对象 | 拟合时是否改变 |
|---|---|---|
| 左侧表达 | 给定细胞的观测 S/U | 训练不改写观测 |
| 中间椭球 | 编码器给出的潜变量近似分布 | 随网络参数更新 |
| 右侧重建 | 根据模型产生的表达预测 | 随模型参数更新 |

## B 两池方程中的每个量

$$
\frac{du_g}{dt}=\alpha_g(s)-\beta_gu_g,\qquad
\frac{ds_g}{dt}=\beta_gu_g-\gamma_gs_g
$$

| 符号 | 含义 | 在估计中的位置 |
|---|---|---|
| u、s | 当前未剪接、已剪接表达 | 作为观测输入和拟合目标 |
| α(s) | 当前表达状态对应的转录速率 | 由调控网络及其参数计算 |
| β | 未剪接 RNA 的剪接速率系数 | 逐目标基因学习的共享参数 |
| γ | 已剪接 RNA 的降解速率系数 | 逐目标基因学习的共享参数 |
| du/dt、ds/dt | 表达的瞬时变化速度 | 用估计参数与当前状态计算 |

同一基因的 β、γ 在细胞之间共享。
α(s) 可随细胞的调控因子表达改变。
方程中的导数通常没有被实验直接测得。

## C 未知量怎样一起受到约束

```flow
观测 S/U -> 潜变量分布: 编码器
潜变量分布 -> 潜变量样本: 重参数化采样
潜变量样本 -> 逐基因潜在时间: 时间解码器
调控参数与速率 -> 两池动力学积分: 当前候选参数
逐基因潜在时间 -> 两池动力学积分: 预测对应时刻
两池动力学积分 -> 预测 S/U: 生成表达分布
预测 S/U -> 训练目标: 与观测比较
训练目标 -> 下一次参数更新: 反向传播
```

latent variable（潜变量）表示模型内部用于描述细胞状态的坐标。
latent time（潜在时间）表示模型为动力学计算估计的时间位置。
潜坐标和潜在时间是两个不同的量。

一次迭代使用当前参数预测表达，再评价预测与观测的相容程度。
重建项、KL 散度和配置相关约束共同影响更新。
学习时间、调控和速率的过程相互关联。
时间尺度依赖模型约定，不直接等于实验中的小时数。

## D 当前网页与真实估计流程的对应边界

| 部分 | 当前网页 | 本地 RegVelo 源码 |
|---|---|---|
| 观测 | 24 个合成细胞、三个基因 | 传入的 S/U 表达矩阵 |
| 编码 | 六维输入、三维分布 | 基因数与潜维度可配置 |
| 重建路径 | 神经网络直接预测表达 | 潜变量到时间，再经动力学生成表达 |
| 动力学拟合 | 人工时间顺序的差分回归 | 动力学参与表达重建和训练目标 |
| 二维布局 | 自写的近邻弹簧布局 | 当前布局不能称为标准 UMAP 实现 |
| 轨迹连线 | 预设教学分组与顺序 | 不能作为独立推断的细胞谱系证据 |

网页可用来观察形状与参数的作用。
讲解真实估计过程时，以 RegVelo 的生成路径为准。
本节不修改网页模型。

## E 本节停点与下一步

训练通过表达预测与观测的比较，为这些未知量提供约束。
